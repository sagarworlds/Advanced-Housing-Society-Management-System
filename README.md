# Advanced Housing Society Management System

A multi-tenant SaaS application for managing housing societies.

## Modules
- User Management & Authentication
- Maintenance & Billing Management
- Gate & Visitor Management
- Complaint & Helpdesk Management
- Facility & Amenity Booking
- Notices & Communication

## Tech Stack
- **Backend:** C# ASP.NET Core (.NET 10), EF Core, SQLite
- **Frontend:** Angular 20 (PWA, Mobile-first)
